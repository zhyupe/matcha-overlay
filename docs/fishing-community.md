# 鱼漂社区统计

在新版 Matcha 插件设置中主动启用“启用鱼漂咬钩时间查询及钓鱼数据上报”后，悬浮窗接收 `FishingStatistics` v1 事件；不直接连接第三方服务。旧版 Matcha 没有此事件时，仍使用手动区间及本地记录。

时间来源按“手动导入 → 鱼漂统计 → 本地记录”选择，显示对应来源和样本数，不混合统计。社区数据严格匹配当前竿、钓场、有效鱼饵与撒饵状态，直接使用毫秒值，不再次减半。撒饵状态未知时只展示未撒饵参考，不参与时间排除。详情提供全部区间、中位数及更新时间。

查询中保留本地候选与计时；刷新保留当前组合缓存，失败回退本地，没有数据时显示“暂无社区样本”。撤销授权立即移除在线统计，忽略迟到事件。在线数据不保存到手动时间区间或本地鱼获备份。

旧记录及备份仍可读取，但只按字段白名单重建，丢弃 `actorId` 和其他额外字段；保存、导出不再携带角色标识。

自动检查：`node tools/fishing/test.mjs`、`node tools/fishing/statistics.test.mjs`。浏览器检查使用 `tools/fishing/browser.mjs` 与 `tools/fishing/statistics.browser.mjs`，通过 `PLAYWRIGHT_MODULE` 指定 Playwright 模块路径，默认连接本地 5178 端口。
