# 外部时间区间导入协议（v1）

悬浮窗「地图事件 → 钓鱼」底部的「导入」按钮同时支持本格式和完整备份格式。其他系统只需输出 UTF-8 JSON 文件，不需要生成角色信息、抛竿事件或鱼获记录。

```json
{
  "format": "matcha-fishing-ranges",
  "version": 1,
  "fish": [
    {
      "fishId": 4891,
      "tug": 2,
      "snagging": false,
      "hookset": "precision"
    }
  ],
  "ranges": [
    {
      "fishId": 4891,
      "baitId": 29717,
      "biteSeconds": [13.5, 19.2]
    },
    {
      "fishId": 4891,
      "baitId": 2585,
      "biteSeconds": [8, 45]
    }
  ]
}
```

示例时间、强度、钓组要求和提勾类型为演示数据，不代表实际鱼种的统计结论。

| 顶层字段 | 规则 |
| --- | --- |
| `format` | 必须为 `matcha-fishing-ranges` |
| `version` | 必须为数字 `1` |
| `fish` | 可选数组，每条表示一个鱼种的属性；最多 10000 条，省略表示不导入鱼种属性 |
| `ranges` | 必填数组，每条表示一个鱼 × 钓饵组合；最多 10000 条 |

| `fish` 条目字段 | 规则 |
| --- | --- |
| `fishId` | 必填正整数，鱼的 `Item` 行 ID；文件内不能重复 |
| `tug` | 可选：1 = 轻杆，2 = 中杆，3 = 重杆；未知则省略，不能填 0 或 null |
| `snagging` | 可选布尔值：true = 必须启用钓组，false = 不要求钓组；未知则省略，不能填 null |
| `hookset` | 可选：`precision` = 精准提勾，`powerful` = 强力提勾；省略表示未知，不能填 null；与 `tug` 独立 |

鱼种属性适用于该鱼的所有钓饵。`snagging: true` 时，关闭钓组会排除该鱼；钓组状态未知时标记条件待确认。`snagging: false` 不限制是否启用钓组。`fish` 和 `ranges` 可分别提供，无需互相包含所有鱼种。

| `ranges` 条目字段 | 规则 |
| --- | --- |
| `fishId` | 必填正整数，鱼的 `Item` 行 ID |
| `baitId` | 必填正整数，有效钓饵的 `Item` 行 ID；鱼饵为鱼时默认以小钓大，填写饵鱼的 Item ID |
| `biteSeconds` | 必填 `[最小秒数, 最大秒数]`，未撒饵时从抛竿到咬钩的基准时间；允许小数、允许上下界相等，不含收杆动画；四舍五入到毫秒后必须是正的安全整数，且下界不大于上界 |

区间不包含 `placeId`、`tug`、`snagging`、`hookset`、`mooch` 或 `chum`。撒饵时显示时间为基准时间 × 0.5；本地撒饵观测时间先除以 0.5，再与未撒饵观测合并。撒饵状态未知的观测不参与时间统计；当前竿撒饵状态未知时显示未撒饵基准区间，并在面板中标注；不按时间判定匹配或超出区间，其他已知条件仍可排除候选。鱼饵是否为鱼由当前鱼种目录、导入数据及本地鱼获识别。

只接受以上字段。ID 不接受名称或数字字符串；未知字段、null、无效上下界和文件内重复组合均拒绝。无需 ID 已收录在前端当前目录中，但生成端须保证映射正确。单文件大小上限为 5 MB。

整份文件验证成功后才合并。鱼种属性按 `fishId` 整条替换，时间区间按 `fishId + baitId` 整条替换；未提供的鱼种、组合和已有鱼获保留。重复导入不会增加副本。新鱼种条目省略 `tug`、`snagging` 或 `hookset` 时，会移除该鱼原先导入的对应字段；仅导入区间不会修改鱼种属性。前端可使用本地观测推断强度，不根据强度推断提勾类型。空数组不清空已有数据。

导入区间和本地观测时间均跨钓场共享。候选鱼种由当前钓场目录及该钓场的鱼获记录确定，导入数据不添加钓场鱼种关系。透明条使用该鱼所有钓饵的区间包络；不透明条使用当前钓饵的区间。两者均按当前撒饵状态缩放。该鱼提供 `hookset` 时，候选鱼行显示提勾类型。

底部「导出」使用完整备份格式（`version: 1`、`catches`、`profiles`、`fish`），其中 `profiles` 时间为未撒饵基准毫秒，`fish` 保存鱼种属性；鱼获记录保留抛竿时的钓场及状态快照。备份可重新导入。读取旧备份或本地存储时，`profiles` 中的 `placeId`、`chum`、`snagging`、`mooch` 会被移除，撒饵区间先换算为基准时间，`tug` 和 `hookset` 移入鱼种属性；旧区间的钓组状态不作为鱼种的钓组要求。不同旧组合映射到同一鱼与钓饵时以文件中最后一条为准，鱼种强度和提勾类型分别取最后一条已提供的值，顶层 `fish` 条目优先；原有完整组合重复仍拒绝。
